## 三、本次已修复（已提交）

1. **一次性引擎重试**（上一轮）：装配/诊断/去AI味/拆原子/出选题/模板等无交互重发的引擎，遇瞬时超时/限流/5xx 自动退避重试，最多 3 次。
2. **选题装配检索 used=0 → 5**（本轮，核心缺陷）
   - **现象**：装配出的初稿看着没问题，但 `used=0` —— 一条素材/原子都没检索到，初稿其实是模型凭空写的，「从你的资产库装配」这一**最核心卖点形同虚设**，「越用越值钱」的飞轮断了。
   - **根因**：用整条选题标题（"我用 AI 做副业的 3 个月复盘"）做 `LIKE '%整句%'`，中文无词边界 → 命中 0。
   - **修法**：segmenter-free 的中文 IR 做法 —— 标题+切入角度展开成 ASCII 词 + CJK 2/3-gram 检索词，逐词检索后按命中的不同词数给资产排序，取 top 6 装配。新增纯模块 `assembly-retrieval.ts` + 8 单测；全量 124 测试通过。

## 四、改进建议（针对中文内容创作者，按性价比排序）

### P1 — 高杠杆 / 小改动
1. **⌘K 搜不到「选题」**：当前全局搜索范围是 对话/素材/原子/笔记，**漏了选题库**。创作者大量时间在选题库里穿梭，应能 ⌘K 直跳某条选题（顺带把发布记录也纳入）。
2. **装配后选题状态不流转**：装配/去改写后，选题仍停在「灵感」，看板永远不动。装配成功应自动推进到「进行」，并把「存为素材」的初稿**回链到该选题**，让看板真实反映创作进度。
3. **装配初稿弹窗缺「诊断/去AI味」直达**：现在只有 复制 / 存为素材 / 去改写，要先跳到改写工坊才能诊断。把这两个动作直接放进弹窗，省一次跳转。

### P2 — 内容创作者打磨
4. **去 AI 味应强绑「人设/品牌口吻」素材**：现在是通用去味。示例里已有「品牌口吻」素材，但 deai 没强制注入。建议让用户把某条素材标记为「人设」，去味时强制用它，改成「我的腔调」而非泛泛口语化 —— 这是创作者第一痛点。
5. **改写平台补中文阵地**：现有 小红书/公众号/抖音脚本/视频号/X。建议补 **知乎 / B站文案 / 头条号**（中文创作者高频）。
6. **知识图谱小数据体验**：素材少时几乎全是孤立节点，力导向把节点堆到一角、标签互相遮挡。建议：按标签聚类着色 + 节点碰撞避让 + 空状态引导「先建立双链」。

### P3 — 信任 / 分发
7. **「本地优先」说明**：素材是创作者的核心资产，中文用户很在意数据去向。设置里只提了密钥加密，建议在引导/设置里点明「全部数据存在本机，不上传」。
8. **失败态文案**：一次性引擎失败时把 `[错误] ...` 直接当初稿塞进正文。已加重试，但仍建议失败时给友好中文提示 + 「重试」按钮。
