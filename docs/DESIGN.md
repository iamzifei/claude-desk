# 墨栖 InkNest — 产品与设计方向

> 从「牛马AI 复刻」演进为**面向内容创作者的 AI 创作工作台**。
> 定位与差异化记录(2026-06-18 自主迭代)。

## 一、定位
**内容创作者的素材库 × AI 创作台。** 面向 YouMind 用户、抖音 / 小红书 / 微信公众号
等平台的图文与多媒体创作者:沉淀自己的素材与上下文,用 AI 高效产出多平台内容。

- 名字:**墨栖 / InkNest** —— 墨(内容创作)+ 栖(创作者素材的栖息地 / 落脚创作)。
- 一句话:一处沉淀素材,多平台高效产出。

## 二、与牛马AI 的差异化(不做像素级抄袭)

### 视觉
| | 牛马AI(参考) | 墨栖 InkNest |
|---|---|---|
| 主色 | 暖琥珀 `#d98a3d` | 冷靛紫 `#6d5dfb`(创意 / AI 气质) |
| 背景 | 暖米白 `#f6f4f0` | 冷调近白 `#fcfcff` / 淡紫灰侧栏 |
| 品牌标 | 「牛」琥珀方块 | 「墨」紫色渐变圆角标 |
| 气质 | 温暖、文书感 | 清爽、创意、年轻 |

整体从「暖」翻到「冷」、从琥珀翻到靛紫,第一眼就是不同的产品。

### 功能差异化
- **素材库(核心差异点)**:创作者把灵感 / 金句 / 数据 / 参考链接沉淀下来,打标签、可搜索;
  开启「入上下文」的素材会**注入到 AI 创作的系统提示**,让 AI 用创作者自己的料。这是
  牛马AI 没有的、面向「维护自己素材与上下文」的能力。
- **创作导向的预设**:小红书 / 公众号 / 抖音脚本 / 视频脚本 / 起标题 / 选题 / 改写润色 /
  评论回复 —— 取代通用的写作 / PPT / Excel 预设。
- **导航重排**:新建创作 · 搜索 · **素材库** · 技能 · 编程 · 浏览器 · 定时任务 · 每日回顾 · 会议纪要
  —— 把创作者高频的素材库 / 技能前置。
- **技能系统**复用为「创作风格 / 人设」的载体(启用即注入系统提示)。

### 保留的底层能力(沿用牛马AI 同款实现)
聊天(流式 / 思考 / markdown / 多供应商)、工作区→项目→会话、卡片预览导出、定时任务、
每日回顾、会议纪要、**离线语音(sherpa-onnx + SenseVoice 同款)**、浏览器自动化、
**真·编程 agent(Claude Code 引擎)**。

## 三、上下文注入模型
创作时,AI 的 system prompt = `启用的技能` + `入上下文的素材`。两者都在主进程
`run.ts` 里拼接,创作者可随时在「技能 / 素材库」里增删与开关。

## 四、质量
- `npm test` —— vitest,7 个文件 34 个用例,覆盖安全护栏(文件写入限定在 cwd、危险 bash 拦截、
  浏览器动作清洗)、调度、解析、供应商、音频重采样、问候语。测试还抓出过一个真实 bug(fork bomb
  正则的 `\b` 永不匹配)。
- 每个功能都用 CDP 在真实 Electron app 里端到端验证过(见 ALIGNMENT.md 各节)。

## 五、待办 / 可继续
- 素材库:支持图片素材、从链接抓取、按平台分组。
- 创作产出:一键多平台改写(同一内容 → 小红书 / 公众号 / 抖音三版)。
- 名字 / 配色若需调整:`Sidebar.tsx` 品牌 + `assets/main.css` 的 `--primary` 一处即可改。
- 打包分发:electron-builder + 原生模块(better-sqlite3 / sherpa-onnx-node)asar unpack。
