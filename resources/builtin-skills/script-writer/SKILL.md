# 短视频脚本 Skill：三模式口播脚本创作

> 一个技能，三种脚本框架：**情绪/观点**（最易上手）、**故事**（难但最立人设）、**干货**（拿收藏、证明专业）。
> 自动判断该走哪条框架，或让用户手动指定；产出可直接开拍的口播稿。

---

## 一、使用场景

在以下情况使用本技能：

- 用户说"帮我写一条短视频脚本 / 口播稿"
- 用户给了一个选题、一段经历或一堆素材，想变成能拍的视频
- 用户输入 `/script`、`/脚本`、`/短视频脚本`
- 上游选题技能（如爆款选题）产出了选题，需要落地成脚本

**不适用**：长文写作（用爆款写作类技能）、图文笔记、纯拍摄分镜设计（本技能以口播文案为主，镜头提示为辅）。

---

## 二、底层创作观（写任何一稿前先过一遍）

这四条是三种模式共享的地基，违反任何一条，脚本大概率没流量：

### 2.1 短视频的"短"是密度的短，不是时间的短

一部电影两小时有十个情绪高点；一条三分钟的视频同样要有足够多的"点"——只是更集中。**信息密度够高、够爆炸，才有人看完**。删掉一切不承载信息或情绪的句子。

### 2.2 文案两原则（每一句话都要过）

1. **特写镜头原则**：把抽象说成"能看见的画面/细节"。
   - 不说"我当时很拼"，说"凌晨两点，电脑上还开着十七个没关的标签页"。
   - 判据：**需要解释的词都不是好文案**。"赋能""闭环""认知升级"这类词一律替换成画面。
   - 变具象的两招：**类比/比喻**（把陌生概念挂到熟悉事物上）；**借共识**（用大家公认的参照物，一句话完成定性）。
2. **小宝宝原则**：当成讲给一个完全不懂这个领域的人听。
   - 不用行话、不绕弯、**一句话只表达一个意思**，听一遍就懂。
   - 判据：把稿子念给一个外行听，他中途皱眉的地方就是要改的地方。

### 2.3 开头期待感三形式

开头唯一的任务是制造"我想接着看"的期待感，只有三种可靠做法：

| 形式 | 机制 | 示例句式（抽象化） |
|------|------|------|
| **不稳定情绪** | 情绪能穿透屏幕，是最大的钩子 | "我今天必须说句得罪人的话……" |
| **圈定人群** | 让某群人一眼觉得"这是讲给我听的" | "如果你也是那种开了店却不敢涨价的老板……" |
| **反认知** | 打破默认预期，制造认知缺口 | "越努力发视频的人，账号死得越快。" |

### 2.4 目标群体必须一句话说得出

写稿前先回答："**这条视频讲给谁听？**"答不出一句话（如"讲给刚起步、想做内容又怕出镜的手艺人"），就先别动笔。"讲给所有人"等于讲给没有人。

## 三、执行流程

### Step 0：模式判定

先根据用户输入自动判断走哪个模式；判断不了就问。

**自动判定规则**：

| 用户输入特征 | 判定模式 |
|------|------|
| 有明确立场/看法/不满/想替某群人说话；素材是"观点+情绪" | **模式 A：情绪/观点** |
| 素材是个人经历、踩坑、转折、创业史、逆袭；想"立人设" | **模式 B：故事** |
| 素材是方法、清单、教程、避坑指南；想"证明专业、拿收藏" | **模式 C：干货** |

**判断不了时的询问模板**：

```
这条视频你想达到什么效果？选一个：
1. 表达一个观点/替一群人说话（情绪观点型——最容易上手，涨认同）
2. 讲一段自己的真实经历（故事型——最难，但最立人设）
3. 教别人一个具体方法（干货型——拿收藏，证明你专业）
```

**给新手的建议**（用户犹豫时主动说）：先从模式 A 练起，最易出效果；模式 B 最有长期价值但需要真实素材打底；模式 C 适合有专业积累的人稳定输出。

### Step 1：信息收集（所有模式通用）

开写前确认四件事，缺了就问：

1. **主题/素材**：这条讲什么？用户提供的原始素材是什么？
2. **讲给谁听**：目标群体一句话（见 2.4）。
3. **人设维度**（可选）：如系统提示中有人设档案，标注这条内容指向哪一维（过去/专业/观点/实力/生活）；没有则跳过，不要追问。
4. **目标时长**：默认 60-90 秒口播（约 250-400 字）；用户可指定。

### Step 2A：情绪/观点模式（总分总）

**结构 = 总分总，三段：**

1. **开头（总）：抛观点 + 圈定人群 + 制造盟友与敌人**
   - 一句话把立场亮出来，同时让目标群体觉得"这是替我说的"（盟友），并隐含一个对立面（敌人：某种论调、某类人、某个惯例）。
   - 示例骨架（抽象化）："现在劝小商家别做线上的，基本自己都没做成过。"——盟友=想做线上的小商家；敌人=唱衰的声音。

2. **主体（分）：3-4 个高分值论点**
   - 每个论点必须"**分值够高**"= 具象、精彩、有共识、**一句话能戳中**。
   - 红线：**平淡、幼稚、堆道理 = 没流量**。一个论点如果需要三句话解释，就换掉它。
   - 每个论点配一个可见的画面或例子（特写镜头原则），不是配一段说教。

3. **结尾（总）：总结升华**
   - 收回到开头立场，给一句能被截图/被复述的话；可给一个极轻的行动暗示。

**两条最高效的选题路由**（素材不够时按这两条挖）：

- **路由一**：给"想做但没做成的事"一个**体面的理由**——当某群人的嘴替，替他说出那个借口。（例：替"一直想发视频却没发过"的人说"你不是懒，是没人告诉你第一条该拍什么"。）
- **路由二**：给"不想做的事"一个**站得住的理由**。（例：替"不想混行业饭局"的人论证"不社交才是小生意人的效率"。）

**三种取材触发**（今天写什么）：热点事件 / 我很共情 / 我想吐槽——从这三个口子找当天的立场。

**模式 A 专属自检**：
- [ ] 论点分值够不够高？（每个论点单拎出来能不能当一条评论区金句）
- [ ] 有没有"体验"？——你得**无比相信 + 带情绪 + 有观点**，观众才信；写成中立分析就废了
- [ ] 是不是真情绪脚本（为立场辩护），没有写串成干货脚本（给解决方案是另一类）

### Step 2B：故事模式（五段框架）

**结构 = 五段，磨难-转机交替推进：**

```
1. 开场钩子：抛一个个人成就 / 特殊经历 / 磨难（让人想知道"后来呢"）
2. 磨难
3. 转机
4. 更大的磨难
5. 转机 → 收：感悟
```

**内置题材库**（从真实经历里对号入座，不是编造模板）：

| 磨难 6 型 | 含义 |
|------|------|
| 一意孤行 | 所有人反对，你偏要做，结果栽了/成了 |
| 恶霸欺压 | 被强势一方（大客户/平台/同行）碾压 |
| 至亲背叛 | 最信任的人在关键时刻反向而行 |
| 强权干涉 | 规则、机构、不可抗力打断你的计划 |
| 过河拆桥 | 帮人成事后被一脚踢开 |
| 奸人所害 | 被算计、被骗、被截胡 |

| 转机 7 型 | 含义 |
|------|------|
| 因祸得福 | 坏事逼出了更好的路 |
| 伙伴加入 | 关键的人在低谷时出现 |
| 贵人相助 | 意料之外的援手 |
| 发现漏洞 | 看见别人没看见的缝隙 |
| 破釜沉舟 | 砍掉退路后反而通了 |
| 通关密码 | 找到那个一直缺的关键方法 |
| 意外之喜 | 无心之举带来转折 |

**故事模式五原则**：

1. **磨难够真、转机够爽**才抓人——磨难写得越具体，转机越解气。
2. **别一上来报喜**：先让人替你揪心，成果和业务藏在起伏曲线里被"看见"，而不是被"宣布"。
3. **全程具象细节**："早上吃面条"级别的画面，不讲抽象概念；观众记住的是细节，不是结论。
4. **卖真不卖梦（红线）**：题材库只是结构参考，**只从真实经历取材，不为戏剧性编造**。可以放大真实（真给过就说给过），不硬造假的。你有真的、别人编不出来——这才是护城河。
5. 每段要有**价值翻转**：段落结束时人物处境/认知和开始时不同，否则这段是平的，删掉或合并。

**挖故事引导问题清单**（用户说"我没什么故事"时，按清单逐题问，通常问到第 5-8 题就有料了）：

*一意孤行类*
1. 你做过最"所有人都反对"的决定是什么？后来怎么收场？
2. 有没有哪次你明知风险还是干了？最坏的时刻是什么画面？
3. 你为一个决定付出过的最大代价是什么（钱/时间/关系）？

*低谷与磨难类*
4. 你最缺钱的时候，账上还剩多少？那天你在做什么？
5. 有没有一段"每天睁眼就是问题"的日子？最具体的一个场景？
6. 被谁狠狠拒绝或看不起过？对方原话还记得吗？
7. 有没有被合作方/平台/客户"卡脖子"的经历？
8. 最接近放弃的那一次，是什么让你停下来没放？

*转机类*
9. 回头看，哪个"坏事"反而救了你？
10. 有没有一个人，在你最难的时候拉了你一把？他做了什么具体的事？
11. 你是什么时候发现"原来还有这条路"的？那个瞬间在哪里、在干什么？
12. 有没有一次破釜沉舟——砍掉退路之后反而成了？
13. 你现在赖以吃饭的方法，最早是怎么被你撞见的？

*落点与感悟类*
14. 如果只能给三年前的自己发一条 20 字的消息，你会说什么？
15. 这段经历里，你现在最想让谁听到？为什么是他们？
16. 有没有一个具体物件（一张单据、一台旧设备、一条消息记录）能代表那段日子？
17. 别人以为你成在哪里，实际你自己知道成在哪里？
18. 这件事之后，你再也不做什么了？

**模式 B 专属自检**：
- [ ] 每一段是否都有可见的细节（时间/地点/物件/原话）？
- [ ] 磨难-转机是否交替（不是一路顺或一路惨）？
- [ ] 是否开场没报喜、把成果留到曲线里？
- [ ] 所有素材是否来自真实经历（红线）？

### Step 2C：干货模式（拿收藏）

**三条硬规则**：

1. **7±2 法则**：论点/步骤最多 7 个（建议 3-5 个）。超过 7 个人记不住，砍掉或拆成下一条视频。
2. **第 18 秒标准**：开播 18 秒内必须出现第一个**可照做的具体动作**——能直接抄的步骤/口令/操作，不是"你要有意识地……"这种玄学。
3. **收藏导向**：干货的目标是"**值得存**"，不是"看着爽"。判据 = **信息够多 + 够陌生**（"这些点我没听过"）。都是老生常谈就没有收藏价值。

**干货的两类价值**（择一主打）：
- **低行动成本 + 见效快**：给确定性——"照这三步做，今天就能看到变化"。
- **够稀缺够陌生**："我没听过"——内幕、冷知识、行业里才知道的门道。

**选题切入七角度**（缺角度时从这里选）：避坑 / 省钱 / 谈资 / 追求更好 / 内幕揭秘 / 行业黑话 / 解决问题。

**推荐结构（解答型四拍）**：

1. **日常难题**（前 3 秒）：点中目标人群每天都在踩、但懒得解决的**具体场景**——不说"你效率低"，说"你是不是每天花两小时把同一条内容改三个平台的版本"。
2. **制造危机**：把不解决的代价算给他看——代价 ×（每天/每周都在发生）= 一笔他没意识到在流的账。三种代价择一放大：偷时间 / 漏钱 / 掉信任。
3. **低行动成本**：转折句立刻松一口气——"但解决它不用学新东西，三步就行"。把门槛压到地板。
4. **解决难题 + 具体方法**：给 2-3 步可直接照做的动作（守第 18 秒标准往前提第一步），最好用一个真实例子收尾兜底可信度。

**模式 C 专属自检**：
- [ ] 第 18 秒内有没有出现第一个可照做的动作？
- [ ] 论点是否 ≤7 个？每个是否都能直接抄？
- [ ] 陌生度：这些点目标观众听过没有？（都听过=重写）
- [ ] 有没有写串成情绪脚本？（干货服务"有用"，情绪服务"共鸣"，一条视频只走一条）

### Step 3：开头三候选（所有模式必做）

不管哪个模式，**正文写完后，按期待感三形式各写一个开头**，让用户自己选：

```
【开头候选】
A. 不稳定情绪版：……
B. 圈定人群版：……
C. 反认知版：……
```

每个候选 1-2 句、≤30 字；三个候选必须真的走三种机制，不是同一句换措辞。

### Step 4：质检自评（见第五节清单）

对成稿逐项打钩，不合格项直接改掉再交付，并在输出末尾附自评结果。

## 四、输出格式模板

最终交付统一用这个格式：

```markdown
# 短视频脚本：{标题}

- 模式：情绪观点 / 故事 / 干货
- 讲给谁听：{一句话目标群体}
- 人设维度：{过去/专业/观点/实力/生活；无人设配置则省略}
- 预估时长：{X 秒，约 X 字}

## 开头候选（选一个替换正文开头）

- **A. 不稳定情绪版**：……
- **B. 圈定人群版**：……
- **C. 反认知版**：……

## 口播稿

【开头】（镜头：近景直面镜头｜情绪：{如"压着火""笃定"}）
……口播文案……

【主体 1】（镜头：{提示}｜情绪：{提示}）
……

【主体 2】……

【结尾】（镜头：{提示}｜情绪：{提示}）
……

## 质检自评

| 检查项 | 结果 | 说明 |
|---|---|---|
| 特写镜头原则（无需要解释的词） | 通过/不通过 | … |
| 小宝宝原则（一句一个意思） | 通过/不通过 | … |
| 开头期待感（三形式之一） | 通过/不通过 | … |
| 目标群体一句话说得出 | 通过/不通过 | … |
| 信息密度（无废句） | 通过/不通过 | … |
| 模式专属自检 | 通过/不通过 | … |
```

镜头/情绪提示保持轻量（每段一行），服务口播表达，不做完整分镜表。

## 五、共享质检清单（三模式通用）

交付前逐项过，任何一项不过就回去改：

1. **特写镜头原则**：稿子里还有没有需要解释的抽象词？（"认知""格局""赋能"→ 全部换成画面）
2. **小宝宝原则**：是否一句一个意思？有没有外行听不懂的行话？
3. **开头**：是否属于期待感三形式之一？是否给了 3 个候选？
4. **目标群体**：能否一句话说出"讲给谁听"？稿子里的每个例子是否都是这群人的场景？
5. **信息密度**：逐句问"删掉这句损失什么"——答不上来就删。短视频的"短"是密度的短。
6. **模式纯度**：情绪没写成干货、干货没写成情绪、故事没写成简历。
7. **真实红线**（故事模式强制）：素材全部来自真实经历，无编造。

## 六、常见失败模式（写完对照排雷）

| 症状 | 病因 | 修法 |
|---|---|---|
| 开头是自我介绍（"大家好我是……"） | 没有期待感 | 换成三形式之一，自我介绍删掉或挪到结尾 |
| 论点像教科书，句句正确没人转 | 论点分值低、堆道理 | 每个论点换成"一句戳中 + 一个画面" |
| 故事一上来就"我现在做到了 X" | 报喜太早，没有揪心 | 重排为磨难开场，成果藏进转机 |
| 干货讲了 40 秒还在铺垫背景 | 违反第 18 秒标准 | 第一个可照做动作提到 18 秒内 |
| 什么人都想覆盖 | 目标群体不清 | 重答"讲给谁听"，砍掉不属于这群人的段落 |
| 视频 3 分钟但只有一个信息点 | 密度不足 | 要么压到 40 秒，要么补足信息点 |

## 七、迷你示例（情绪/观点模式，抽象案例）

以"某社区面包店主，讲给同样开小店、被平台抽成压得喘不过气的店主听"为例，展示合格产出的粒度：

```markdown
# 短视频脚本：小店别再迷信外卖平台了

- 模式：情绪观点
- 讲给谁听：开实体小店、外卖占比越来越高却越干越亏的店主
- 预估时长：约 70 秒，300 字

## 开头候选

- **A. 不稳定情绪版**：今天关掉外卖平台的那一刻，我居然松了口气。
- **B. 圈定人群版**：如果你的店外卖单越接越多、月底却越算越亏，这条是讲给你的。
- **C. 反认知版**：外卖单越多的小店，死得越快。

## 口播稿

【开头】（镜头：店内收银台前，直面镜头｜情绪：压着火、笃定）
外卖单越多的小店，死得越快。这话是我关了两年外卖之后才敢说的。

【主体 1】（镜头：举起一张外卖小票特写｜情绪：摊开算账）
一单 25 块的面包，平台拿走 6 块 5，包装 2 块，满减我出 3 块——
到手 13 块 5，房租水电还没算。你不是在做生意，你是在给平台打工。

【主体 2】（镜头：切到店门口排队画面｜情绪：转折、松弛）
我把这 6 块 5 换成了什么？换成每天出炉时间发在顾客群里。
三百人的群，一条消息，当天就能清空一炉。

【主体 3】（镜头：回到面部近景｜情绪：替同行说话）
不是你不努力，是这套抽成规则本来就不是为 8 张桌子的小店设计的。

【结尾】（镜头：近景｜情绪：收束、留一句话）
小店的出路不在平台的流量池里，在你家三公里内那三百个熟客手里。
```

要点复盘：开头走反认知；三个论点分别是"一张小票的账"（特写镜头原则）、"一条群消息清空一炉"（可见的转机）、"规则不为小店设计"（当嘴替）；无一个需要解释的抽象词；目标群体一句话可说。

**故事模式合格粒度参照**（仅示意开场，不展开全稿）：
> "2019 年我把家里唯一一套房抵押了 47 万，所有人都说我疯了。"（开场钩子=磨难+一意孤行，数字具体、无形容词）

**干货模式合格粒度参照**（仅示意第 18 秒动作）：
> 开播第 15 秒："第一步，现在打开你的订单后台，把近 30 天复购两次以上的客人拉一个单独的群——就这一个动作，今天做完。"（可照做、零门槛、有截止）
