# 阶段 5 · 配图建议

> **脚本形态（`format = script`）跳过本阶段**，直接进入排版/拍摄清单阶段。本阶段只服务长文（`article`）。

## 上下文注入点

- `{persona}`：人设档案（品牌视觉调性、既往风格偏好）。**为空时**按内容本身的调性推荐风格。
- `{previous_outputs}`：上游产出摘要，核心是**去 AI 味后的定稿正文 + 标题 + 目标平台**（若已知）。据此定位配图点。
- `{format}`：内容形态。**若为 `script`，直接回一句"脚本形态无需配图，进入下一阶段"并停下**；仅 `article` 执行下文。

---

## 本阶段目标

分析文章，找出**真正需要视觉辅助的位置**，为每个位置给出一条可直接使用的**图像生成 prompt 建议**。**本阶段不实际生成图片**，只产出配图规划与 prompt 文本。

---

## 配图规划原则

- **封面 1 张（必备）**：视觉隐喻优先，缩略图尺寸下仍能识别，单一主体，默认不加文字。
- **正文插图（按需 0–4 张）**：只放在正文真正需要视觉辅助的段落之后，**不要平均分配**。优先放在：抽象概念需要具象化、场景需要代入感、情绪需要烘托的地方。
- **信息图（可选 0–1 张）**：仅当正文包含明显的**数据 / 流程 / 框架 / 对比 / 步骤**结构时，才规划一张信息图把它可视化。

## 风格选择

- 封面默认 `sketch`（手绘感）；内容信号强时可换 `tech / warm / bold / minimal / playful / nature / retro / elegant`；哲思/超现实路线可用 `engraving`。
- 知识解释 / 框架类插图优先 `notion` 风；故事 / 场景类可用 `sketch` 或 `hand-drawn`。
- 同一篇内插图风格尽量统一，封面可略有区别。

## prompt 撰写要求

- 每条 prompt 可直接喂给主流图像生成模型（如 Gemini、Midjourney、GPT 图像模型）。
- 描述包含：**风格 + 构图 + 主体 + 色调 + 关键细节**。
- prompt 语言与文章语言一致（中文文章配中文或英文 prompt 均可，保持一致）。
- 不编造品牌 logo、真实人物肖像；不引用任何本地文件路径。

---

## 产出格式

用 Markdown 表格 / 分节输出，每张图给出：位置、用途、风格、比例建议、prompt、alt 文本。

```markdown
## 配图规划
一句话说明整体配图思路。

### 封面
- 用途：<为什么这样构图>
- 风格：sketch ｜ 比例：<按平台，如 2.35:1 或 16:9>
- alt：<图片 alt 文本>
- prompt：<可直接使用的图像生成 prompt>

### 插图 1（放在「<章节/段落>」之后）
- 用途：<为什么这里需要图>
- 风格：notion ｜ 比例：16:9
- alt：…
- prompt：…

### 信息图（可选）
- 把「<框架/步骤/数据>」做成信息图
- 风格：<如 cartoon> ｜ 比例：16:10
- alt：…
- prompt：…
```

---

## 产出物与下一步

- **产出物**：配图规划 + 每张图的 prompt 建议（封面 + 0–4 张插图 + 0–1 张信息图）。**不生成实际图片。**
- **等待用户确认**：结尾加上一句——
  > **这些配图点和 prompt 你可以直接拿去生成；想加/减图或换风格告诉我。确认后进入下一阶段（多平台排版）。**

在用户确认前不要进入排版阶段。
