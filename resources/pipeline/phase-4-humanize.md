# 阶段 4 · 去 AI 味

## 上下文注入点

- `{persona}`：人设档案（尤其语气、既往偏好——哪些表达要避免 / 偏好保留）。**为空时**只做通用去 AI 味，保留作者原有声音。
- `{previous_outputs}`：上游产出摘要，核心是**阶段 3 的定稿正文**（长文或脚本）。这是本阶段要处理的文本。
- `{format}`：内容形态（`article` / `script`）。影响体裁判断与改写口吻；脚本更口语、更短句。

---

## 核心立场

**去 AI 味 ≠ 写出好内容。** 识别 AI 痕迹是为了让文字更像真人，而不是把所有人都洗成同一种"自然腔"。每种 AI 痕迹背后都有作者本来想达成的意图——所以**先审计、再改写**，不要一上来就整篇重写。

---

## 第一步：审计（列出 AI 痕迹清单，先不改）

逐处引用原文，标注命中的痕迹类型 + 严重度（高/中/低）+ 一句诊断。常见 AI 痕迹：

| 痕迹 | 说明 |
|---|---|
| **并列三连** | 连续三句以上排比、三词并列凑气势 |
| **否定式对比** | "并非…而是…" / "不是 X，而是 Y" / "X，而不是 Y" 等所有否定式套句 |
| **时代开场** | "在这个…的时代 / 当下 / 背景下" |
| **名词化 / 抽象堆叠** | 把动作说成一串抽象名词，读者要在脑子里翻译 |
| **多重修饰** | 一个名词前挂三四个定语，句子拖沓 |
| **空转过渡** | "其实 / 事实上 / 总的来说 / 值得注意的是 / 然而 / 此外" |
| **总结戳** | "一句话总结 / 简而言之 / 综上所述" |
| **节奏过均匀** | 句长方差太低，读起来像机器匀速吐字 |
| **礼貌填充 / 条件菜单** | "如果你愿意，我还可以…"这类流程性空话 |

**审计输出格式**：

```markdown
# AI 痕迹审计
体裁判断：{长文 / 短视频文稿}（依据：字数、语态、句长）
命中：共 X 处

**第 1 处**【高】
> {引用原文}
{一句话诊断}  ·  类型：否定式对比

...

总结：{1–2 句概括最突出的问题}
```

---

## 第二步：改写（正向注入两原则）

在去掉 AI 痕迹的同时，**正向注入具象与人味**——不只是删套话，而是把每一处替换成更好的表达：

1. **小宝宝原则**（行话 → 白话）：一句话只表达一个意思，外行听一遍就懂，不用行话、不绕弯。
2. **特写镜头原则**（抽象 → 可见细节）：把抽象结论换成能看见的画面、数字、物件、原话。需要解释的词都不是好文案。

改写纪律：

- **保留作者真声音**：改的是 AI 腔，不是作者的观点、立场、个人化表达。
- 不要用"不是 X，而是 Y"去改写"不是 X，而是 Y"（别用一种套句换另一种）。
- 打破过均匀的节奏：长短句交错。
- 收尾直接落在判断或建议上，不要先写"总结一下"。
- 保持原意与事实不变，不为了"更像人"而改动数据、人名、结论。

---

## 产出格式

1. **AI 痕迹审计清单**（第一步的输出）。
2. **改写后全文**（长文或脚本，标准 Markdown；脚本保留【开头】【主体】【结尾】与镜头/情绪提示）。
3. **改动摘要**：一句话说明主要改了哪几类痕迹、注入了哪些具象细节。

---

## 产出物与下一步

- **产出物**：AI 痕迹审计清单 + 去 AI 味后的定稿 + 改动摘要。
- **等待用户确认**：结尾加上一句——
  > **看下改写版，哪里改过头或想保留原样告诉我；确认后我进入下一阶段。**
  > 下一阶段：`article` → 配图建议；`script` → 直接进入排版/拍摄清单（配图阶段跳过）。

在用户确认前不要进入后续阶段。
