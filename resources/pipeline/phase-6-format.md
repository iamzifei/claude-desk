# 阶段 6 · 排版

## 上下文注入点

- `{persona}`：人设档案（语气、目标平台偏好）。**为空时**保持内容原有语气，按平台通用规则改写。
- `{previous_outputs}`：上游产出摘要，核心是**定稿正文/脚本 + 标题**（长文还含配图信息，可在版本里预留图片位置说明）。
- `{format}`：内容形态。**`article`** 走"多平台改写分支"，**`script`** 走"拍摄清单分支"。为空默认 `article`。

---

## 本阶段目标

把定稿变成**可直接发布 / 可直接开拍**的形态。长文做多平台适配，脚本做拍摄化整理。

---

## 分支 A：长文形态（`format = article`）—— 多平台版本改写

**一次只输出用户指定的平台版本，不要批量生成。** 若用户已在上下文里指明目标平台，直接输出该平台版本；否则先让用户从下面选一个。保留核心观点，调整语气与长度以适配平台调性。

| 平台 | 字数 | 规则 |
|---|---|---|
| **公众号** | 1500–2500 | 长文，Markdown 可直接排版；保留小标题，结尾留互动/引导钩子 |
| **小红书** | 标题 ≤ 20 字，正文 + tag ≤ 1000 字 | H1 标题，短段落，更口语、更感性，结尾带 3–10 个话题标签 |
| **知乎** | 长文 | 专业深度，保留论据与引用，适合分析型长文 |
| **微博** | ≤ 140 字 | 一句 punchline + 一个钩子 |
| **X 中文短帖** | ≤ 280 字 | 强观点、强节奏，可作线程首条 |
| **X 长文** | 1500–3000 字 | H1 标题，2–4 行短段落，每 3–5 段一个小标题，关键洞察加粗，结尾关注 CTA；像和朋友聊天，不讲课，每段一个观点 |
| **X 英文短帖** | ≤ 280 字 | **意译不直译**，把中文意象换成英文等价物 |

**附传播文案**：输出平台版本后，同条消息附上该平台的转发/传播文案：

- 公众号 → 朋友圈转发文案（2–3 句 + 引导点击）
- X 长文 → 一条推文（≤ 280 字）
- 小红书 / 知乎 / 其他 → 微信群转发消息（口语化）

排版纪律：不要在正文里插"下面是某平台版本""适合发布"这类描述性句子；有配图则用占位说明标出图片位置，不引用本地路径。

## 分支 B：脚本形态（`format = script`）—— 拍摄清单

把定稿口播脚本整理成一份可直接开拍的**拍摄清单**（替代多平台改写）：

要求：

1. 完整保留定稿口播文案（以去 AI 味后的定稿为准），按【开头】【主体 N】【结尾】分段。
2. 每段给一行镜头提示（景别 / 拍摄位置或动作）和一行情绪提示（语气 / 节奏），保持轻量，不做完整分镜表。
3. 头部给**拍摄准备块**：预估时长、讲给谁听、场景与道具清单（从文案推导，如小票、电脑屏幕、店门口）。
4. 尾部给**发布备注**：建议封面文案一句（≤ 16 字）+ 可复制的视频简介一段（≤ 60 字 + 2–4 个话题标签）。
5. 不新增口播内容、不改写观点，只做拍摄化整理。

输出结构：

```markdown
# 拍摄清单：<标题>

## 拍摄准备
- 预估时长：…
- 讲给谁听：…
- 场景与道具：…

## 分段口播
### 【开头】
- 镜头：…
- 情绪：…
> <口播文案>

### 【主体 1】
…

### 【结尾】
…

## 发布备注
- 封面文案：…
- 视频简介：…
```

---

## 产出物与下一步

- **产出物**：长文 → 指定平台版本 + 传播文案；脚本 → 完整拍摄清单。
- **等待用户确认**：结尾加上一句——
  > **长文：需要哪个平台的版本继续告诉我（一次一个）；脚本：拍摄清单可直接开拍。发布并攒够数据后，回来用下一阶段（复盘）分析效果。**

不要一次批量生成所有平台版本；不要擅自跳到复盘阶段。
